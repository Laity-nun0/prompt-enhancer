# 数据处理说明

## 哪些内容会发送给模型

点击“增强提问”后，应用会通过独立 Codex App Server 向 OpenAI 模型发送当前草稿、所选对话中的用户和助手消息，以及按需读取的项目目录结构和相关源码。多个对话模式会发送所选来源的合计内容。范围检查还会使用相同证据检查生成结果。

“独立对话”模式下点击发送，也会向模型发送消息。快捷键唤起、草稿编辑和单纯刷新对话不发起模型生成；启动和登录仍需要与账号服务通信。应用没有自建云端数据库或统计服务，不将用户会话写入 GitHub。

本地运行、只读文件、运行时的 read-only 沙箱及关闭工具网络权限，不代表模型推理离线或源码不会离开电脑。服务端如何保存、使用模型输入取决于 OpenAI 当前服务政策、账号设置及组织约定，本项目不承诺零保留或默认不训练。可从 [OpenAI 数据控制说明](https://help.openai.com/en/articles/7730893-data-controls-faq)核查自己账号的适用设置。

## 本地保存内容

下列 state/ 默认指 %LOCALAPPDATA%\PromptEnhancer\state；可用 PROMPT_ENHANCER_STATE_DIR 指定其他非空绝对路径。

- `state/codex-home/`：独立登录凭据、配置、模型缓存及运行时保存的对话和日志。它不复制 Codex Desktop 的凭据；仍属于敏感账号数据。
- `state/projects.json`：本地项目路径和独立 Thread ID 映射。
- `state/profile/`、`state/runtime-workspace/`：运行时使用的隔离用户目录及空的运行时工作目录。
- `state/login-url.txt`：首次登录期间的临时授权链接，不应分享。
- `state/ui-session.json`：界面状态、模型和项目路径。`state/electron-user-data/`、`state/electron-session-data/` 保存 Electron 用户数据和缓存。`.local/` 中的验收报告可能包含输入及生成结果，不随产品打包。
- `%LOCALAPPDATA%\PromptEnhancer\desktop-sessions`：导入的 Desktop 对话副本、标题、消息、时间、路径及可选 Hook 事件。
- 系统剪贴板：只有桌面增强完整通过校验后，才写入最终结果。

这些位置不进入 Git 提交或发布 EXE。运行数据位于用户目录，删除源码或程序目录不代表删除本地状态；清理本地数据前应先退出应用并判断是否需要保留对话记录。旧源码 `.poc/` 的登录、用户目录、项目映射和 Electron 缓存可迁移到新状态目录；迁移不删除旧源、不复制测试数据，所以旧目录仍可能保留敏感数据。删除独立登录目录后需要重新登录，不要把凭据复制给其他使用者。

## 文件读取保护及其上限

读取器拒绝路径越界、符号链接/目录联接、明显凭据及内部数据目录，并限制目录、文件数量和正文大小。`.local/`、`.poc/`、`.codex/`、`.agents/`、`.aws/`、`.ssh/`、`.azure/`、`.kube/`、`.docker/` 等目录，以及 `.env`、`.npmrc`、`.netrc`、`auth.json`、常见私钥等文件被排除。

这是明确的排除规则，不是完整的秘密识别器：自定义文件名中的账号、密钥、客户资料或未公开数据仍可能被读到；所有项目 `.gitignore` 规则不会自动生效。对话本身也可能包含敏感信息。选择项目、对话和草稿前，请确认你有权把其中的内容发送给模型。

当所选来源或已读文件在增强期间变化，应用拒绝交付结果并要求重试。模型来源标签校验与范围检查不能保证内容完全正确，发送前仍应审阅生成文本。
