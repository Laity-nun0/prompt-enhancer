## 已处理的问题

首次验收最初在 Electron 图形启动阶段失败。最小隐藏窗口的 A/B 检查确认：仅覆盖本机 Electron 的 USERPROFILE 即导致原生进程崩溃，而正常环境、单独 HOME 或 LOCALAPPDATA 变更可启动。现已保留 GUI 的 Windows 系统用户环境，仅隔离 Node 后端，并为该验收实例单独设置 Electron 缓存目录。修复后的真实登录和完整增强通过。

## 验证范围

以上是同一台机器上的干净源码安装和全新应用状态验收，不是另一台电脑或新建 Windows 系统账号的测试。合成 Desktop 历史验证导入与增强流程，不代替所有 Codex Desktop 版本的真实历史格式兼容性检查。

没有验证 Linux、macOS、Windows ARM64、离线模型或公网多人服务。浏览器登录、网络、账号及模型权限仍是每位使用者的必要条件。模型生成和范围校验存在误判可能，用户仍须审阅结果。

本地原始报告位于被忽略的验收状态目录；不提交 OAuth URL、凭据、账号资料、真实会话或生成正文。GitHub CI 只执行离线检查，以各提交对应的 Actions 结果为准。
