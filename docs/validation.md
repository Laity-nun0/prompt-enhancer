# 发布前验证记录

## 交付形态

正式发布为 Windows x64 免安装单文件 `Prompt-Enhancer-Windows-x64.exe`。双击直接运行，无需安装、CMD 或外部 Node.js。内部资源会自动展开到系统临时目录，退出后清理；账号、项目映射和缓存保存在用户目录，不随 EXE 删除。

`release/win-unpacked/` 是构建调试目录，分发时使用正式单文件 EXE。程序没有代码签名证书，Windows 可能提示未知发布者。

## 验收要求与范围

- 确认正式单文件 EXE 实际生成，并直接测试其资源展开、无需外部 Node 的启动、托盘、快捷键和退出清理。
- 迁移检查须保留旧源，不覆盖目标已有状态、不复制测试材料，并重定位会话数据库路径。
- 首次 OAuth、真实项目与模型选择、一次真实增强及剪贴板结果需要另行验证，不能以构建成功或窗口出现代替。

尚不能据此声明 Linux、macOS、Windows ARM64、离线模型或公网多人服务受支持。浏览器授权、网络、账号及模型权限仍是每位使用者的必要条件。模型生成和范围校验存在误判可能，用户须审阅结果。

本地验收材料位于被忽略的 `.local/`；不提交 OAuth URL、凭据、账号资料、真实会话或生成正文。GitHub CI 只执行离线检查，以各提交对应的 Actions 结果为准。
